# Mergington High School Activities

A super simple website application that allows students to view and sign up for extracurricular activities.

## Features

- View all available extracurricular activities
- Sign up for activities
- Share activities through WhatsApp, Facebook, X, or a copied link

## Sharing an activity

Use the sharing options at the bottom of any activity card. Social sharing opens
the selected service in a new tab, where you can review your post before sending.
Choose **Copy link** to send an activity through another app; if automatic copying
is unavailable, select and copy the link shown below the button.

Shared links highlight the activity when opened. Only the activity name and link
are shared, not participant details. Sharing does not require a teacher login.
Friends need access to the website, so use its public address rather than
`localhost` when sharing.
